# FootballTransfers

Учебный пример на C# по диаграмме классов регистрации футбольного трансфера.
Каждый класс, интерфейс и перечисление находятся в отдельных файлах.

Запуск при установленном .NET 8 SDK:

    dotnet run

`Program.cs` показывает два случая: трансфер игрока из клуба и трансфер
свободного игрока. В примере используется `InMemoryTransferRepository`,
поэтому база данных для запуска не нужна. В репозитории сохраняются только
зарегистрированные трансферы. `GetByWindow` возвращает их за указанное окно.

`DbTransferRepository` реализует тот же интерфейс и работает через ADO.NET
`DbConnection`. При его использовании приложению нужно передать фабрику
подключений к базе с поддержкой SQL-команды `CREATE TABLE IF NOT EXISTS`.
Конкретный провайдер базы данных в этот учебный проект не добавлен.

Перед обработкой игрок вызывает `AcceptTerms` для покупающего клуба и цены.
Флаги `AllowsRelease` и `AllowsOffer` в `Club` представляют уже принятое
клубом решение. При отказе или ошибке проверки трансфер получает статус
`Rejected` и не сохраняется; при успешной регистрации — `Registered`.
